# Angular Photo Library

An Angular application for browsing a stream of photos and saving favorites. The project is currently under development.

## Prerequisites

The project has been verified with:

- Node.js 26.13.0
- npm 12.2.2

## Getting started

Install dependencies:

```bash
npm ci
```

Start the development server:

```bash
npm start
```

Open [http://localhost:4200/](http://localhost:4200/) in your browser. The application reloads when you change source files.

## Tests

Run the unit tests once:

```bash
npm test -- --watch=false
```

## Build

Create a production build:

```bash
npm run build
```

The build output is written to `dist/gallery-template/`.
